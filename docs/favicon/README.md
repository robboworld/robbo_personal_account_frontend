# Фавикон ЛК

Голова робота-маскота: зелёная голова, белый экран, лицо цвета головы, тёмно-зелёные уши и ножка антенны.

| Исходник | Куда идёт |
|----------|-----------|
| `robot-head-16.svg` — пиксельный, по сетке 16×16 | `public/favicon.ico`, кадр 16 px |
| `robot-head.svg` — сглаженный, viewBox 32×32 | `public/favicon.ico`, кадры 32 и 48 px; `public/apple-touch-icon.png` (180 px: робот 140 px по центру на белом фоне — iOS заливает прозрачность чёрным) |

Две версии нужны, потому что сглаженная в 16 px размывается в пятно, а пиксельная в крупных размерах выглядит как пиксель-арт.

SVG-фавикон в `index.html` не подключать: Chrome берёт SVG для всех размеров и перестаёт использовать 16-пиксельный кадр из ICO.

Пересборка после правки исходника: отрисовать каждый SVG ровно в целевом размере (без масштабирования готового PNG) и упаковать 16/32/48 в ICO с PNG-кадрами (32 бит, прозрачный фон).
